# DOMINUS Platform Website

Public GitHub Pages showcase for **DOMINUS**, a proprietary market-intelligence, evidence-governance and staged execution research platform.

## Public purpose

This repository is the public presentation layer for the project. It is intentionally limited to static HTML, CSS, lightweight client-side JavaScript and original first-party visual design.

It is not the DOMINUS production or research repository and contains no authenticated trading runtime.

## Public positioning

DOMINUS is presented at product level around these themes:

- chronological market observation;
- deterministic research decisioning;
- evidence governance and provenance;
- broader market / external-context research;
- staged promotion from research toward later bounded execution;
- explicit separation between research evidence and authenticated order authority;
- `NO_TRADE` as a legitimate outcome under insufficient evidence or degraded conditions.

The website does **not** claim guaranteed profitability, production deployment, certification, independent security validation or live-trading readiness.

## Publication boundary

The underlying DOMINUS software remains private / proprietary IP. This public repository intentionally excludes:

- proprietary source code and algorithms;
- internal strategy logic, formulas and model details;
- private datasets and test vectors;
- credentials, API keys, tokens, private endpoints or environment secrets;
- internal runbooks and deployment material;
- private validation artifacts;
- authenticated execution interfaces;
- reconstruction-level architecture detail.

A public website repository does not make the underlying software open source.

## Site architecture

```text
index.html   public product showcase
styles.css   responsive visual system
script.js    accessibility-aware navigation / reveal behavior
favicon.svg  original first-party DOMINUS mark

```

No external JavaScript frameworks, trackers, advertising SDKs, web fonts or image CDNs are used.
